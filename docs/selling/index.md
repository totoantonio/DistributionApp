# Selling

Every sale follows the same path, from the first order to the delivered goods:

1. **[Customers]({{ '/selling/customers/' | relative_url }})** — add a customer; the admin approves them.
2. **[Sales Orders]({{ '/selling/sales-orders/' | relative_url }})** — a salesman or staff member writes the order and submits it.
3. **[Approvals]({{ '/selling/approvals/' | relative_url }})** — the approver checks credit and stock, then approves. The invoice is made automatically.
4. **[Invoices and Delivery]({{ '/selling/invoices-delivery/' | relative_url }})** — the warehouse packs, the driver delivers, and payment terms start counting.
5. **[Returns and Cancelling]({{ '/selling/returns/' | relative_url }})** — credit memos for goods sent back, and cancelling an invoice.

{: .note }
Getting paid is in the next chapter, **Collecting**.
