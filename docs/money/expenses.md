# Expenses

Go to **Expenses** → **+**. Fill in the date, category, payee, description, amount, method and reference no.

- **Categories** — pick one from the list or type a new one.
- **Charged to Salesman** — link a cost (fuel, allowance) to a salesman so it shows in their performance report.

Filter the list by date, category or person, print it, or export it to a spreadsheet (CSV).

{: .note }
Deleting an expense needs a reason. Expenses made by payroll can't be edited here — reopen the payroll instead.
